

# Face Beauty (Lipstick and FaceMask)
El proyecto de demostración para Android que aplica Canvas para maquillaje facial (Labial y Mascarilla Facial) utilizando la [biblioteca principal CameraX](https://developer.android.com/jetpack/androidx/releases/camera)
y [Google ML Kit](https://developers.google.com/ml-kit/vision/face-detection/android).

El contenido principal incluye:
- Labial
- Mascarilla Facial
- Capturar y guardar imágenes
- Compartir imágenes
